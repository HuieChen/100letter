# 一百信 · 制作锚点

玩家是 Solmere 邮局的新邮差，处理无法确认寄件人与收件人的特殊信件。通过世界观察、多轮交谈、检查与修复真实信件作出推断，再承担投递和修改的人的后果。核心体验是清楚、流畅、可以自主发现的解谜，而不是任务说明面板。

保留用户认可的早间游戏、横版手绘二维场景、现有角色、旧五案与存档。大色块、清楚轮廓、Solmere 夏日配色；世界纸张和系统信息分开。封面仅纯底色与游戏名字，不再生成封面画。所有改变以 CURRENT_SPEC.md 和最新反馈为依据。

制作顺序由 production/studio-board.json 管理：档案 → 信袋/信封 → 地图 → NPC → 行走与反馈 → 三封信新流程。已有自动回归不代表这些链已被玩家验收；旧五案不替代三封信的新内容。三封信需要实测至少30分钟有效游玩，不能靠等待或跑腿凑数。

一条链先确定玩家动作、依赖与错误/退出路径，再写代码，审查实际画面、真实操作和声音，修复、复测、交接。当前缺口见 QA_REPORT.md 与 docs/REQUIREMENTS_REVIEW_20261003.md；不能因工作室模板已经接入而宣称游戏质量提高或完工。
