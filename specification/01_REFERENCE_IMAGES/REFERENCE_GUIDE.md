# 游戏参考分工表

## 一级参考
- Faefever — https://store.steampowered.com/app/1276550/Faefever/
  - 负责：整体推进类型、2D point-and-click、小镇调查、人物访谈、多种解法、叙事与谜题融合。
- Genuine Article — https://store.steampowered.com/app/5089930/Genuine_Article/
  - 负责：物证观察、没有发光答案、玩家自己判断、检查工具只是放大信息而不替玩家解题。
- Forgery Craft — https://store.steampowered.com/app/1540720/Forgery_Craft/
  - 负责：文件拆解、工具影响成品、组合工具产生不同结果。Solmere 只借“操作逻辑”，不做现实可复制的伪造教学。
- Papers, Please — https://store.steampowered.com/app/239030/Papers_Please/
  - 负责：桌面信息并置、文件空间管理、有限压力、工作身份带来的抉择。
- Return of the Obra Dinn — https://obradinn.com/
  - 负责：人员档案、交叉证据、延迟确认、玩家自己建立人物/时间/地点关系。

## 二级参考
- HER TREES : PUZZLE DREAM — https://store.steampowered.com/app/3300800/HER_TREES__PUZZLE_DREAM/
  - 只借：拼合、折叠、对齐、排列、缺失信息带来的视觉顿悟。
- Strange Horticulture — https://store.steampowered.com/app/1574580/Strange_Horticulture/
  - 只借：固定工作区、地图/图鉴/对象同屏、温和节奏下的 contextual clue。
- The Westport Independent — https://store.steampowered.com/app/352240/The_Westport_Independent/
  - 只借：删减信息会改变意义，“不撒谎也可能不说全部事实”。
- Orwell: Ignorance is Strength — https://store.steampowered.com/app/633060/Orwell_Ignorance_is_Strength/
  - 只借：事实与“被传递出去的信息”可以不同。

## 统一原则
参考游戏只负责各自层级，不允许把任意一款的完整 UI、关卡、角色、文本、视觉资产照搬。
