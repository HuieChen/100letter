# UI / UX / 交互规格

## 1. 邮局工作台
默认画面只显示：今日信件托盘 + 当前信件 + 3 个主入口（地图/档案/工具）。不要把所有工具铺满。

### 信件列表
每封显示：外观缩略图、类别图标、是否急件、状态（未处理/调查中/待投递/已处理）。不显示“正确率”。

## 2. 信件检查模式
- 双击/按钮进入聚焦模式。
- 鼠标拖动信封。
- 点击边缘翻面。
- 滚轮/按钮缩放。
- 可把一个档案卡拖到旁边对比。

## 3. 拆信模式
步骤：检查封口 → 选工具 → 沿游戏化路径操作 → 打开 → 取出内页/附件。
工具手感要不同：
- 安全工具：移动慢，容错大，耗游戏内时间较多。
- 快速工具：操作快，容错小，容易留下裂痕。

## 4. 修复模式
- 折痕对齐：拖信纸对齐半透明轮廓。
- 边缘修复：将碎边放到正确区域。
- 封合：拖修复带/盖虚构修复印。
- 结束后不弹分数；玩家自己看信封是否自然。

## 5. 地点场景
使用用户锁定建筑原图作为舞台核心。
交互热点覆盖在图上：门牌、公告、时刻表、旧标签、窗边等。
热点悬停只做轻微 cursor change，不发光描边。

## 6. NPC 对话
- 每次最多 2–4 个问题。
- 问题来自当前案件上下文，不做几十项 topic tree。
- 已问过的问题淡化。
- NPC 说完关键线索后自动记录到档案，但不自动解释结论。

## 7. 人员档案
左侧人物卡；右侧确认信息。
可把人物卡拖到当前信件旁做对比。
未知信息留白。

## 8. 错误与反馈
错投不 Game Over。
表现为：退信、NPC 困惑、后续关系变化、声望状态改变。
