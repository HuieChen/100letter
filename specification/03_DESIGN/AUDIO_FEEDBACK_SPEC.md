# 音频与操作反馈

## 环境
- 邮局：轻微室内风声、远处海鸥、纸张、老风扇/钟表极轻。
- 公交站：海风、远处车辆、公交刹车极轻。
- 观景台：海风更明显、远船鸣笛极轻。
- 社区中心：远处人声模糊底噪。

## 交互 SFX
- 纸张 pick/drop：2–3 个随机变体。
- 信封 flip：短、干净。
- 邮戳：木质轻敲。
- 纸片拼合：正确靠近时小纸摩擦，不要“叮”。
- 修复完成：非常轻的纸面压平声。
- 投递：信件落入信箱 + 很轻的主题音符。

## 音乐
- 主调：温暖夏日、轻木吉他/钢琴/手风琴/brush percussion。
- Case 04：减少节奏与配器，留更多空气。
- Case 05：只保留主题旋律简化版，不做恐怖 Drone。
