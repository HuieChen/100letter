# Solmere Post — MVP Game Design Spec

## 核心一句话
在异常邮件岗位上，通过物证、地点与人物关系推断信件真正应该去哪里，再决定信息是否应该抵达。

## 试玩长度
30–45 分钟。

## MVP 一天
09:00 到岗 → 5 封异常信 → 自由排序调查 → 17:30 左右进入 Case 04/05 收束 → 18:00 结算。

## 玩家动作集合
- Pick up letter
- Flip / zoom / compare
- Inspect clue
- Open directory
- Open map
- Travel
- Inspect environment hotspot
- Ask limited question
- Delegate to NPC
- Open letter (if allowed)
- Restore damaged/opened letter
- Deliver / Delay / Hold / Return / Delegate
- End day

## 互动设计底线
任何“关键动作”都不能只是点一个按钮然后播放文字。
例如：
- 残损信必须拖碎片。
- 拆信必须操作工具。
- 修复必须对齐和封回。
- 地图必须呈现移动成本。
- 人员档案必须能并排对比。

## 谜题语法
70% 现实信息推理 + 20% 物件操作 + 10% 特殊顿悟。
每个核心谜题尽量具备：
- 1 条物件证据
- 1 条世界/地点证据
- 1 条人物证据
- 拆信作为可选强证据

## NPC 信息原则
- 默认诚实。
- 误导来自：记错、信息过期、片面认知、关系偏见。
- 仅 Case 04 允许一个有明确动机的主动隐瞒。
- 谎言必须能被独立证据拆穿。

## 时间压力
- 不做现实倒计时读信。
- 旅行消耗游戏内时间。
- 急件截止时间只影响特定 Case。
- 让玩家在“继续查”与“先送”之间产生压力。

## 人文感
- 每封信至少透露一个生活细节：旧店名、社区活动、家人鼓励、过去关系、搬迁、等待。
- 线索不是纯功能文本，应该让玩家记住这个镇的人。
- 但不要把每个 NPC 都写成长篇背景。
