# 美术方向与资产规则

## 1. 目标
建立一个“像正式独立游戏、但体量小”的 2D point-and-click MVP。美术不追求高写实精细度，而追求：
- 统一
- 清楚
- 低细节
- 有辨识度
- 可读性强
- 不像 AI 堆料

## 2. 画面层级
每个场景固定 4 层：
1. 背景底色/地形
2. 用户 LOCKED 建筑或地点单体
3. 独立可交互物件热点
4. UI / 对话 / 信件

人物层单独存在，绝不烘焙进背景。

## 3. 用户现有素材策略
- 不统一重画。
- 不通过 AI “让它们看起来一样”。
- 新素材反过来适应用户素材：减少细节、降低纹理、用相近的扁平色块语言。
- 主角和尘缘只允许原图出现；如需要对话，可用原图裁切显示但不得修改图像内容。若项目中裁切也被视为修改，则直接显示完整立绘并用 UI 遮挡布局。

## 4. Faefever / Crushed in Time 的使用方式
- Faefever：二维舞台、手绘简化、人物与地点是清楚的层，不追求真实空间。
- Crushed in Time：只借几何概括和极清楚的轮廓，不借 3D 材质与光照。

## 5. 背景要求
- 每张背景 3–6 个大形状即可。
- 不做复杂砖墙纹理、木纹、花纹。
- 海、天空、山用大色块。
- 树木/植物用 2–3 层形状，不画叶片细节。

## 6. UI
- 纸张卡 + 青绿标签 + 珊瑚急件色。
- 统一圆角非常轻，避免现代 App 感。
- 文字全部运行时渲染，不把长文本烘焙进图片。

## 7. 画面密度
任何界面都遵守：主焦点 1 个，次焦点最多 2 个。若画面同时出现地图、人物、五封信、六个工具，必须分阶段显示，而不是全堆一屏。
