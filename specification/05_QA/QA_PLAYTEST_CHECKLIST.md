# QA / Playtest Checklist

## A. 可玩完整性
- [ ] 新存档可从 Title 进入游戏。
- [ ] 5 个 Case 都可以开始、调查、处理、结算。
- [ ] 任一 Case 错投不会导致死档。
- [ ] 关闭游戏后 Continue 能恢复最近关键节点。

## B. LOCKED 素材
- [ ] SHA256 与包内 manifest 一致。
- [ ] 主角未被 AI 重画。
- [ ] 尘缘未被 AI 重画。
- [ ] 7 个地点建筑未被 AI 重画或融入新背景。

## C. 交互
- [ ] 信封可拖、翻、放大。
- [ ] Case 03 纸片拼合必须由玩家操作。
- [ ] 拆信不是单按钮完成。
- [ ] 修复不是单按钮完成。
- [ ] 地图移动会消耗游戏时间。
- [ ] NPC 代送有真实代价。

## D. 谜题公平性
- [ ] Case 01 至少有 2 条可观察证据。
- [ ] Case 03 不拆信也理论可解。
- [ ] Case 04 至少 3 条独立证据能确认 Sender/Recipient。
- [ ] Mira 的隐瞒可以被别的证据拆穿。
- [ ] 没有任何核心答案只能靠猜。

## E. 情绪与人文
- [ ] 五封信不是五个“工具任务”，每封都有生活语境。
- [ ] Case 04 的选择没有“善恶”UI。
- [ ] Case 05 收束为不安/苦甜，不转恐怖。

## F. 美术
- [ ] 新素材是 2D 扁平低细节。
- [ ] 没有写实厚涂、复杂 3D、电影光影。
- [ ] 每屏主焦点不超过 1 个。
- [ ] UI 不堆纸张和花卉装饰。
- [ ] 长文本全部运行时渲染而非烘焙进图。

## G. 节奏
- [ ] 试玩 30–45 分钟内可完成。
- [ ] 前 5 分钟内完成 Case 01，玩家理解基本规则。
- [ ] 10–15 分钟内第一次体验 NPC 代送或急件压力。
- [ ] 15–25 分钟内第一次完整体验拆信/修复。
- [ ] 后半段 Case 04 明显提升推理与情绪强度。
- [ ] Case 05 控制在 6 分钟内，不拖长。
