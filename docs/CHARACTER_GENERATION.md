# Painted character assets

Built-in `image_gen` was used on 2026-10-01. No API/CLI fallback was used. **No supplied user character, building, reference screenshot, or locked original image was uploaded or used as an image input.** The first courier, Nora and Chenyuan were generated from text. Subsequent edits used only these newly generated images; the courier sheet was the style reference for the residents.

Shipped files are in `assets/characters/generated/`: `courier_sheet.png`, `nora.png`, `chenyuan.png`, and `atlas.json`. The PNG files are copied unmodified from the image-generation tool outputs. Atlas regions and foot anchors are read by Godot at render time; no bitmap pixel reconstruction, procedural limb drawing, or source-art deformation is involved. The first rough generation and intermediate resident versions are retained in the tool's generated-image directory, not referenced by the game.

The courier has eight walking images, two standing images, an envelope-offer pose and a reading pose. `CourierActor` selects these painted images. `StageWalker` retains actual movement, acceleration, manual WASD/arrows, target cancellation and arrival callbacks. One walking cycle covers 142 stage pixels; footsteps occur at each 71-pixel contact. All pose shoe lines use the same ground anchor. The handoff/inspect are held gesture poses with a return to idle, not full multi-frame hand animation. The generated up/contact drawings remain similar; this is an eight-pose game loop, not a claim of studio-clean traditional animation. The residents are single standing paintings.

## Prompt set

First eight cells request left/right contact/down/passing/up walking phases; bottom four request two neutral idle poses, envelope handoff and inspection. Explicit constraints included natural forward knee bends, opposite arm swing, constant scale and ground line, no geometric primitive character art, no text, and no user-source likeness.
