# 本轮发布说明

当前是 Godot 4 的可玩 MVP：五封信、七处场景、四位居民，包含调查、行走、投递与日终存档。原始规格保留在 `specification/`；后续用户授权的叙事扩写、绘画环境和展示透明度处理均另行记录。

本轮主要修复：

- 开局直接进入邮局门前，以当前目标和现场交互提示引导；目标随观察、问话和信封翻面更新。放大世界界面文字，移除常驻长地点说明。
- 六类重点证物加入翻转、移开、对齐和选择等观察操作，实际看见隐藏信息后才能记录；普通线索仍可直接查看，阅读不扣游戏时间。
- 标题、结尾与七处外景使用绘画环境；更新 Mira、June 立绘。邮局及社区中心仅清除已批准的外围窄白边，保留原件、完整画布和全部 RGB。
- 修正居民楼上方行走边界；居民与主角在独立人物层按脚点前后排序，避免远处人物盖住近处人物，同时保留前景、热点和对话层级。真实移动与交谈回归为 26 项通过，原行走回归为 37 项通过。
- 补充纸张、脚步、开门和场景环境声，以及独立音量与静音设置；声音来源、处理步骤和许可有记录。

已实现的规格主线：旧地名投递；日落急件的亲送、代送与迟到；六片地址拼合及可选拆封；旧信三项独立物证推理和四种处理；十一行旧清单比对及归档、私留、销毁结尾。第三封与第四封均可不拆完成；拆信后有实际展开和复原操作，旧照片需按选择归置。错误投递可重试，工具损坏可回到操作检查点。前四封可自由安排，第五封在其处理后解锁；不以善恶分数评价旧信选择。

与原规格的边界及尚未验证事项：

- 急件仍以 18:00 为截止；迟到后保留实际时间并允许收工，不强行把时钟倒回 18:00。后续叙事扩写保持谜题事实，但正文不再逐字等同原稿，见 [内容扩写记录](CONTENT_EXPANSION.md)。
- 棋摊与塔楼屋可探索，未制作独立棋类、塔罗或厨房小游戏；这些不阻断五封信。当前为固定二维场景和有限人物动作，不是完整小镇日程模拟。
- 30–45 分钟是设计目标，尚无真人通关时长或满意度数据。100 条模拟路线是自动化状态测试，不是 100 名真人试玩，也不证明谜题难度、紧迫感或美术统一性已获认可。
- 自动化报告按各次实际运行记录范围与源码状态；后续改动不能借用旧结果宣称整包通过。最终发行包、完整实机回放及视觉听感复核，以对应交付证据为准。尚未完成商业发行所需的真人体验、广泛硬件兼容和权利终审。
