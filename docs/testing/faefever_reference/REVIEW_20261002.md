## 宣传片实际可见序列

| 约秒数 | 本轮直接可见 | 可用于 Solmere 的边界明确的决定 |
|---|---|---|
| 20–23 | 主角走在连续地面，前景剪影遮住局部；横向空间保留 | 走路、地面、前后遮挡同属场景，不靠悬浮对象列表导航 |
| 27–29.5 | 市长与主角同框；底部对话区域从三句选项变为姓名和回答，约占画高四分之一 | 对话保留现场；选项和回答共用一个低位区域，不并列长问句墙 |
| 29.5–33 | 店内两句选项，随后姓名、逐渐出现的短回答及下箭头 | 短句可分段；不能从剪辑断定哪种输入推进或准确打字速度 |
| 36–38 | 箱内滑块近景，底部横块位置改变 | 物件占主要操作面积；不是文字解法按钮。未见完整求解/进入退出 |
| 38–40 | 撬针位置和锁柱高度变化 | 工具与目标空间关系可见；没有足够证据重建全部物理规则 |
| 44–48 | 双页册在场景上方，侧面分类签；内容换为待办、人物页 | 记录成为可翻物件，分类位置稳定；不照抄正文/人物/图案 |
| 48–52 | 左右浏览画框；所选画框呈现背面便条 | 翻面有信息作用；附近场景仍可见。未见点击条件，不能臆造旋转手势 |
| 0–19、40–44、52–65.5 | 宣传文字、过场、标志 | 不视为游戏可操作 UI 或完整结尾 |

直接素材只供研究，不进入游戏或发布包；源清单、分段 SHA 和实际图像在 `work/faefever_official/`。`frames.json` 记录样本与边界。没有取音轨或试听，**听感未验**。宣传片内含剪辑，不能把相邻镜头自动写成连续玩家操作。

另对约 20、28.5、50.5 秒三张完整 1280×720 图复核：行走镜头人物约 270px 高，对话近景人物约 500px 高；对话区域约从 y540 延至底边，左上袋/册组合约宽 310px。这些是画面比例近似测量，说明人物和实体 UI 需要足够可见；不是要求照搬像素，也不证明近景由哪种输入触发。

## 对正式五案回归的具体要求

1. 新班现场、取物、调查近景、合册返回分别截图；近景关闭返回原地点/物件状态。
2. 物件必须真实拿起、翻面、检查/修理、收好；测试使用实际输入，不调用完成回调。
3. 对话用实际姓名/短段和在场人物；不以试验 dummy 文本冒充五案内容。
4. 原五案顺序仍是实际处置 → 回邮局填写判断/去向 → 人工复核 → 拖章留印；原型 S13 的演示顺序不覆盖正式业务逻辑。
5. 分别验证不开封完整路线、受托回执、授权外修、旧件/HV/职员封、五张处理单后收工；GPU 合格不等于真人满意或美术已获认可。
