# Dear Somewhere · 开始后的双场景邮局

用户先要求把拼接邮局图放进项目并加入右箭头，随后明确「这个是点了开始之后的场景」。因此本次接到正式 New Shift 流程，独立看图场景仅保留为辅助检查入口。

## 这次可操作的状态链

封面开始 → 左柜台与主管对白 → 关闭对白 → 右箭头 → 右工作间 → 点击真实桌面 → 原有锁扣、箱盖、取信、检查 → 返回右工作间 → 左箭头 → 左柜台 → 点击真实门 → 原邮局外景。

- 左边画出的书直接打开实体档案；Esc 回到同一房间。
- 场景中的 Esc 由主游戏暂停处理；嵌入组件不再把 Esc 当作关闭独立预览。
- 忙碌或有书本、对白、暂停弹层时，箭头不能从背后响应键盘焦点。审查发现该风险后加入导航许可检查。
- 切换内部房间不扣旅行时间、不授予线索、不转移邮件。工作台返回右房间，不闪回左图。
- 邮局存档的继续入口是左柜台；其他地点仍恢复原世界位置。旧存档格式与个人进度不变。
- 电话、打字机及其他尚未迁移的绘制物件不添加假热点。此轮不宣称它们已可使用，也不宣称新三信剧情完成。

## 原图与包装

源 JPEG 为 3840×1080，SHA256 `5bef8c44b16c09eb31d60395b6b4d56b11b574d9ba70acdd2ccb2f8de1e04e8b`；项目副本与源文件逐字节一致。通过 AtlasTexture 取左右区域，中线两边各略去六列以排除紫色导线与 JPEG 色边。没有 AI 重画、生成填充或图片重新编码。

素材登记：[provenance.json](../../assets/authoring/post_office_20261019/provenance.json)。主游戏直接引用新房间组件，导出选择单明确包含这张原图并验证其授权哈希；其他既有生成美术登记和用户 Settings/视频例外不变。
