## 参考与采用原则

- [A Short Hike 开发者介绍](https://blog.playstation.com/2021/08/05/crafting-a-tiny-open-world-a-look-behind-the-scenes-at-the-creation-of-a-short-hike/)：参考小尺度世界的可读性，在正常游玩画面下确认运动能被察觉，不用全部物体同时大动制造热闹。
- [TOEM 开发者介绍](https://blog.playstation.com/2021/08/31/relaxing-photography-adventure-toem-out-september-17-on-ps5/)：参考安静观察的节奏，环境活动为探索和拍照提供细节，保留原音乐主次关系。
- [GPU Gems 3 第6章，EA/DICE树木风动](https://developer.nvidia.com/gpugems/gpugems3/part-i-geometry/chapter-6-gpu-generated-procedural-wind-animations-trees)：采用根部约束、不同部分的响应延迟和错相思路。
- [GPU Gems 3 第16章，Crysis植被动画](https://developer.nvidia.com/gpugems/gpugems3/part-iii-rendering/chapter-16-vegetation-procedural-animation-and-shading-crysis)：区分主干与叶片的运动，限制弯曲幅度，防止把整体拉长或把硬物变软。

这些是运动与体验原则参考；没有拷贝上述游戏美术、声音或开源代码。本轮没有改变已有音频资产或设置页音色，预览使用现有生产混音。仍需以玩家实际观看、试听和交互反馈作为主观接受标准。
