# Courier pace and camera correction — 2026-10-31

## Scope and actual changes
Latest feedback: walking resembles a slideshow, Shift feels strange, and the return to front takes too long. This pass changes motion presentation, not scene art, facial drawings, game content or saves.

- The coastal parent previously followed the courier before the child advanced. Camera follow now responds to the committed foot-position signal, including initial placement, so character and street update together instead of one render frame apart.
- Shift's target speed changes from 1.65x to 1.35x with a 200ms smooth ramp. Ordinary speed remains 200 world pixels/s. Gait phase still follows actual travel rather than resetting or accelerating independently. Release while D remains held smoothly returns to ordinary speed.
- Stopped-foot settling changes from 140ms to 70ms; the five-pose return changes from 400ms to 240ms. All intermediate orientations remain present at 30/60/144fps. Starting again reverses the current orientation rather than restarting at front.
- Original poses were separately resized to 704px high during extraction. Runtime registration now compensates with a common source scale: `704 * 2195 / source_height`. Verified alpha-positive connected silhouette heights are 2227, 2186, 2195, 2195, 2229px. Existing foot anchors remain unchanged. This restores relative authored proportions without modifying sprite pixels. Cropping already lost original canvas offsets; this is not a claim of recovered exact canvas registration. Alpha threshold uncertainty is below approximately 0.6 world pixels at the current display size.
