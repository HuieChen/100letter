# 参考分工与当前实现

更新：2026-10-01。依据用户原规格中的九项玩法参考，以及后续明确的步行、场景构图、人文叙事和实际操作要求。本页描述当前工程的可定位行为；早期问题及修复记录移入 `testing/REVIEW_ROUNDS.md`。参考关系是设计对应，不能等同参考作品的规模、完成度或玩家口碑。

## 视觉与人物来源

`Crushed in Time` 是额外的形状、构图与色块参考，遵守用户的二维要求，不据此引入 3D 体积或照明风格。场景由独立建筑、程序环境层、物件和人物组成，新增图像与用户原件分目录。七地点原件及旧版本共 13 份全部保留并通过哈希复核。

用户 2026-10-01 后续明确允许本地移除外围白底：展示副本保留完整尺寸和所有 RGB，仅改变批准范围内的 alpha；没有把锁定图交给 AI。具体来源、范围和验证见 `ASSET_PROVENANCE.md`、`DISPLAY_DERIVATIVES.json`、`testing/ASSET_DISPLAY_VERIFICATION.json`。

可步行的舞台角色是独立程序绘制的游戏化形象，不是把锁定主角交给 AI 改动作，也不冒称原概念图的原始动画。完整主角概念图保留为工作证展示来源；其最终暂停入口需与运行界面一致。不得为了维护早期“静态主角”方案而删去用户后来明确要求的步行玩法。

## 人文叙事如何进入交互

五封信保留不同轻重：茶会与甜饼、车票与等待、搬家后的志愿值班，再到旧关系中的自辩和前任工作习惯。NPC 使用已发生的核对作为谈话语境：尘缘指向更新的轮值公告，Nora 回应确认新去向，June 先问年份与封口，再承认自己未必知道何时想读。

27 条现场文字已去掉反复替玩家宣布道理的句子，保留纸张、物件和可核对内容。没有统一的哲学结尾，也没有把所有小镇物件都写成道德寓言。Mutazione、Unpacking 和 A Short Hike 的补充来源与具体采用范围见 `testing/PLAYER_REVIEW_BASIS.md`；没有复制它们的台词、美术或角色。

## 验证边界

截至本轮报告，自动主场景流程为 200 项检查、0 失败，核心专项 224 项检查、0 失败；100 条合成核心路线为 4,976 项断言、100 完成、0 失败。它们分别验证实际界面接线/指针输入和核心状态路径，范围与报告位置见 `testing/REVIEW_ROUNDS.md`。

这些数字不是 100 位真人试玩，不证明满意度、首次理解、叙事感染力或 30–45 分钟时长。最终录屏应来自当前版本的真实窗口；重定位后的所有热点、长文最后一行、人物与原图同框、照片交接、失败恢复及日终都应有对应操作证据。
