## 可执行的原图边界

- 禁止将任何锁定原图上传给图像生成或图像编辑 AI，亦不得作为 AI 的参考输入、image-to-image、inpaint 或融图输入。
- 禁止重绘、换脸、改动作、改衣服、改建筑结构、裁切、补全、调色、重采样源文件或覆盖旧原件；透明度处理仅限下文用户明确批准的外围白底例外。
- 原件只允许逐字节复制，以及引擎内完整等比缩放、平移、显示/隐藏、独立覆盖物件和下述已授权整景昼夜受光。批准的展示副本另存；不可把建筑烘焙进新生成的背景。
- 用户提出人物与场景协调时，应调整新增人物、独立环境层及界面；不以编辑原图、修改源 RGB 或单独重色建筑来统一画风。用户也明确要求昼夜光照：运行时世界层的建筑、人物与环境共同接受 `Light.ambient_at()` 色调过渡，属于整景显示效果，不会改写原件或展示副本的 RGB。源像素校验通过不代表屏幕上各时刻的颜色完全相同；两者须分开描述。
- 新旧原件同时保留。Godot 自动生成的 `.import` 与导入缓存是派生文件，不替代原件；完整性检查始终读取原图文件。

## 哈希验证事实

### 用户批准的展示副本例外（2026-10-01）

用户随后明确批准仅在本地移除场景图外围白底。此授权允许生成 `assets/display_user/` 展示副本，不允许覆盖 `assets/locked_user/` 原件，不允许 AI 输入、重新绘制、裁切、改色或改变画布尺寸。原先“完全不抠图”的边界只在这个具体操作上放宽，不能据此扩大到建筑内部、人物或其他编辑。

实际方法及七个副本的来源/结果哈希在 `DISPLAY_DERIVATIVES.json`：只把与外围相连的近白区域透明度置零，RGB 保持原值，完整画布保留。初次处理在邮局、社区中心两份 JPEG 分别清除 1,531,555 和 1,382,697 个像素的 alpha。用户随后同日明确授权修正外围残留 JPEG 白边：只在固定的初次外部透明区 3 个源像素以内，追加清除 RGB 最小值至少 228、最大通道差不超过 20、且与外部四邻接连通的近白像素。邮局追加 7,768、社区追加 11,414，最终清除总数为 1,539,323 和 1,394,111。距离基准不迭代扩张，超过该窄带或不符合近白条件的新增 alpha 变化为零。公交站与观景台 PNG 仍各清除 1、2 个；另三份 PNG 没有清除像素，五份 PNG 展示副本的文件哈希也未改变。不要把后三份重新编码后的不同文件哈希误当成原图受损。

独立只读复核已写入 `testing/ASSET_DISPLAY_VERIFICATION.json`：13 个保留原件全部 SHA-256 通过，七个展示副本哈希与清单一致、尺寸相同、每个 RGB 像素相同；变化仅是符合已授权条件的 alpha 清零。最新只读复核 `tools/verify_display_assets.py` 使用连通分量标记（独立于生成脚本的传播函数）检查四邻接外部连通性，并重新检查 JPEG 附加变化到固定基线的欧氏距离最大为 3 个源像素。没有修改任何 RGB 像素，尺寸保持原样。标题、地图与场景通过 `_scene_art()` 优先读取批准的展示副本；原件映射仍可由目录追溯。

27 个调查点按完整源图坐标重新定位；显示用纸张/门牌是独立程序物件，不被写回原图。位置与可见门窗、站牌、椅子等的对应见 `SCENE_HOTSPOTS.md`。原图没有现成留言册、问题盒或完整棋子，不能把这些新增物件冒称用户原稿的一部分。

本轮已逐文件验证：七个当前地点文件与七份新附件全字节相同；原包九张锁定图仍全部匹配原包清单；新增四份文件复制后再次计算 SHA-256，全部匹配来源。

原包 `SHA256_LOCKED_ASSETS.txt` 有一个既有清单错误：它把自己的哈希写成空文件哈希 `e3b0c442…`。该条不是图片损坏；九条图片记录全部通过。没有为了让清单表面通过而修改原包文本。

解码像素比较仅用于说明新旧 JPG 是否视觉相同：以同一解码器读取整张 ARGB 像素后计算签名，未另存、重编码或修改图片。像素一致不替代逐字节验证。

### 外围窄白边复核范围

`tools/build_display_assets.py --preview-dir <目录>` 可先输出候选展示副本；无参数时更新正式展示副本和清单。`tools/verify_display_assets.py` 只读验证原件、RGB、尺寸、alpha 资格和独立连通性。两脚本依赖 Pillow、NumPy、SciPy。

本次实际 Main GPU 比较图留在 `test-results/composition_audit/`，邮局与社区各有 `*_before.png` 和 `*_alpha_candidate.png`。候选图当时通过测试夹具直接加载相同的 RGBA 输出；随后两份正式展示 PNG 已重新导入。这组比较证明授权的窄白边修正，不代表后来更新的七张环境绘画与人物的最终合成效果。RGB 中原有混白颜色仍保留；不能把透明度修正表述为重新绘制或完全统一画风，最终视觉效果仍需查看对应版本的合成画面。
