一百信 · Solmere Post

双击 100letter.exe 开始。
首次到岗：点击邮局门前的门，取出第一封信。
信封正反面都有信息；WASD / 方向键或鼠标点击地面行走。
点击物件与人物，走近后查看近景物证或在场景中交谈。
画面中的当前目标会随信件和调查更新；近景中的文字、日期和痕迹需要亲自查看。
信袋、地图和档案在屏幕下方；地图先查看路线与用时，再决定出发。
按住信封纸边拖动；点右边缘翻面；字区滚轮阅读，纸边滚轮缩放。
拼纸时右键旋转。工具台需要实际拖动、对齐和封回。
Esc 暂停 / 返回；F11 全屏。
暂停菜单的“声音设置”可分别调整音乐、音效和环境音，也可主静音。
声音偏好独立保存，静音保留各项音量，不影响游戏进度。

阅读不会消耗游戏内时间。急件18:00前交付；路程、工具操作与邮班交接会推进一天。
关键操作自动保存，继续工作可接着上次记录。
严重拆封事故可从本次操作前恢复；普通错投会退回信件，不会清空调查。

本版包含五封信的调查、投递与结算；棋摊和塔楼屋的两个可选小游戏为预留内容。
这是可游玩的五封信版本，并非完整商业发行。
“全流程演示.mp4”是程序按真实界面操作录制的完整演示，使用独立存档，含剧情与解法剧透。
视频按1倍播放速度呈现，阅读与操作间停顿较紧，不代表首次游玩时长。
100条模拟路线是自动验证，不代表100名真人试玩或满意度结果。
