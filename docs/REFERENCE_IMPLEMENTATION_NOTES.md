## 最新用户参考分工与最终包

用户最新纠正：**Crushed in Time 图 9fcfe1973b2bf3b082be1c26e309eb17.jpg 强参考的是几何廓形**，即块面概括、转折、剪影与物体比例，不能再把其重点写成暖色／光照。Fly to Butterfly Valley／四张彩铅图与 Faefever 负责简约二维手绘笔触及轮廓；配色跟随已有美术素材，不自定全局橙黄。拒绝写实材质、厚涂、均匀矢量描边与刻意扭曲。此前三轮候选被拒绝，不代表画风通过。47b59031 图仍只作构图／配色辅助。

**一般场景 HUD、现场对白与世界推进以 Faefever 为第一参考；档案／人物／故事记录的信息架构、页间导航、证据关联和推断流程 UI 强参考 Obra Dinn。** 后者不只借用推理，外观、手绘纸页、轮廓与图案仍采用 Faefever，不照搬 Obra 单色视觉。彩铅漫画格不是 UI 分镜要求。Crushed 的几何美术职责不来自有限的控制证据。原稿、建筑及用户参考图不喂 AI，外围去白窄授权不扩展。完整覆盖见 USER_DECISIONS（本地历史资料，未随公开源码发布），新增 UI 验收见 保真计划（本地历史资料，未随公开源码发布）。

最新构图覆盖：用户重传截图对应的本项目原生图已找回，证据见 U9 / G1（本地历史资料，未随公开源码发布）。最初大前景柜台、左柜、中央 3×4 格柜、右海景窗和钟的近景结构得到明确认可；后来大空地房间版被拒绝。该近景不强塞全身行走人物，所有地点只留现实合理的主要功能物件。现有封面也被否定，不能把房间图随意叠文字视为完成。

最终包要求五份独立参考成果和更完整流程观察。**本页没有因此升级为全片观看、完整研究或听音验收。** 新 Forgery playtest、HER YouTube 与 Obra 长片见 差异计划（本地历史资料，未随公开源码发布）；尚未访问的来源不沿用旧地址的不可访问结论。旧 v4 案件映射（Nora、身份三栏、取附件等）不是新五案权威，当前采用最终 Case Bible。

本页综合两份 v4 阶段工作草稿、[既有研究记录](testing/GAMEPLAY_RESEARCH.md) 与根代理当时新增的观察。**视频画面均按提供该观察的根代理记录转录；整理者没有再亲自看一遍，更没有完整看完或通关这些作品。** Genuine Article 官方网页文字由整理者在该研究阶段直接核验；本次最终包文档更新没有重做网页核验。物理交互代理取得的官方说明和图文攻略仍按各自证据类型列出。
