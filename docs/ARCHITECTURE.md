# 实现边界

`GameSession.gd` 是时间、线索、信件归属、处理结果与结局的唯一规则入口。界面报告物件操作完成，不能因为打开了一个面板就奖励证据。静态数据集中在 `data/game.json`，场景与人物通过稳定 ID 引用。

`main.gd` 负责切换邮局、现场、地图、工作台、对话与章节首尾；通用纸张、物件按钮、光照、角色行走、拆封、照片与推断板各自独立。`StageWalker` 接近目标后才调用动作，换目标、开面板或离开场景会取消旧回调。

`PhysicalBoard` 统一处理碎片、拆封、封回和清单比对。`AttachmentBoard` 只安排信与照片；确认安排后仍需封回，才调用最终交付规则。`DeductionBoard` 接受三份已知而独立的证据，允许登记错误对应，不在摆放时泄露正确推断。事实复核发生在日终。

新存档、普通保存、检查点、坏结局恢复全部通过 `SaveData`。检查点只保存一层快照，不嵌套历史检查点。严重拆封事故不会授予内页；恢复时回到操作前。旧记录缺少新增字段时补默认值，不覆盖已经存在的玩家进度。

原始美术、授权显示副本、独立新图形分目录维护。时间只改变独立环境与光照层；原图颜色不被重映射。画面坐标统一按 1600×900 布局，窗口等比适配。

测试分层：核心规则 → 单独物件输入 → 主场景接线 → 100 条完整状态路线 → 可见窗口人工操作 → 程序操作的完整加速演示。最后两种与真人盲测有明确区别。
