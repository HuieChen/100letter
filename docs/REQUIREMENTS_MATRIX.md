# 当前需求与验收矩阵

依据原始规格与用户后续要求，按当前源码、目录和已有运行证据核对。`specification/` 保留原样；后续授权扩写及新增资源另行记录。下表描述实现，不把代码存在、生成成功或自动化通过等同真人体验验收。具体测试结果、时间和源码状态以文末报告为准，不在此重复累计数字。

## 原图、视觉与现场引导

| 要求 | 当前实现与可复核证据 | 验收边界 |
|---|---|---|
| 使用最新七张地点图，保留所有版本 | `data/game.json` 保留七项原件映射；四份不同文件另存，三份相同文件复用；`ASSET_INTEGRITY.json` 记录十三个原件。标题、地图与现场通过 `_scene_art()` 优先读取批准的展示副本。 | 原件哈希与展示副本校验见来源记录；不能用外观相近代替字节核对。 |

## 游戏与叙事

| 要求 | 当前实现与证据 | 边界 / 体验验收 |
|---|---|---|
| 五封信调查、选择并到日终 | 五信、七地点、四位居民；前四封可自由安排，处理完后第五封解锁。`GameSession` 保存案件、时间、物证及选择。 | “自由顺序”不包含在前四封之前开启第五封。棋摊与塔楼屋活动明确预留，非主线必需。 |
| 拖、翻、放大、长文完整阅读 | `MailCard` 支持纸边拖动与缩放、边缘翻面、文字区滚动；物证卡和人物卡可留在桌面。 | 主场景回归覆盖正反面与末行；字能显示不代表阅读节奏已获真人认可。 |
| 观察取得真实信息 | 旧地名、迁出记录、旧门牌、时刻表、活动档案、笔迹六类关键记录需先移动遮挡或核对可见细节，再盖章记录；普通观察保持直接。`visual_evidence.gd` 提供两阶段提示及键盘操作。 | 不把全部热点变成重复操作税；记录前不授予对应线索。独立组件中的其他模式不冒称均已接入主线。 |
| 不同案件采用不同推理 | 旧地名；今日行程与代送；拼纸后核对搬迁；姓名、日期、笔迹交叉比对；完整邮件编号与记录状态。 | 仍需真人说明“证据为何相关”，自动化无法证明玩家理解了推理。 |
| Case 03 不拆也可解 | `repair_address` + `resident_moved` +（`lookout_schedule` 或 `nora_registry`）；公开登记与志愿轮值提供替代去向来源。 | 六片拼合恢复的是旧地址，还需调查迁出；不依赖私人正文 `case03_body`。 |
| 拆信和复原是实际动作 | `PhysicalBoard` 提供安全/快速工具轨迹、手动展开、折痕、边缘、修复带和印章；保存物理进度、痕迹及材料。损坏可恢复操作前检查点。 | 操作与存档回归已有记录；触控适配和不同输入设备手感未作广泛验收。已处理信件不能重复操作。 |
| 代送先征得同意，有信息代价 | `delegate_terms` 限定当面正式托付；交付后不可追回，不授予亲自送达才有的 `early_bench`。 | 代送与亲送的叙事差异不是额外道德评分。 |
| 地图具有实际路线与时间选择 | 地图以模态叠层保留底层场景和桌面卡片；选择目的地只预览，明确出发才扣时。公交站到观景台可选步行或按时刻表乘 17 路，显示候车、旅时与预计到达。 | 地图打开时桌面不可同时操作；不是任意线路公共交通模拟。关闭预览不扣时。 |
| Case 04 不拆路线公平，至少三物证 | 旧门牌、同日活动名单、独立署名卡公开可取；照片仅拆后取得。将物证拖到地址、日期和寄件依据，再登记双方身份；旧信 M. / July 18 可与署名卡比较。 | 推断登记不立即判真，结构合法不等于事实正确；真人推理难度仍待评估。 |
| Case 04 到场处理、延迟后果 | 投递与退还检查现场和收件人；暂扣无需无意义往返。投递、暂扣、退回和留下照片有不同晚间反馈，没有善恶分数。 | 当前后果以晚间叙事及记录表达，不是完整可探索的后续关系模拟。 |
| 留下照片是实际删减信息 | `AttachmentBoard` 支持照片翻背及拖入信封或保留区，之后封回并交付；取消不提前提交选择。 | 正文不可自由改写；照片状态、修复材料和最终动作需保持一致。 |
| Case 05 对应十一行记录 | 清单含近似编号与日期，需将旧信与准确记录对应，再选择归档、私留或销毁。 | 核对正确编号只解决事实，不规定处理方式的道德答案；前任身份不揭晓。 |
| 阅读没有现实倒计时 | 观察、对话、档案不扣时；旅行、工具和正式邮班交接推进游戏时钟。急件按实际交付与 18:00 比较；逾期仍可继续日终。 | 不把时钟倒回截止时刻；实际紧迫感不能从路线测试推断。 |
| 多声部书信与具体人物心理 | 五封正文按用户要求扩写，保留核心句、事实与署名；日常轻信与矛盾较深的旧信区分，问答回应已知证据。见 `CONTENT_EXPANSION.md`。 | 运行时正文不再与原规格逐字一致；没有真人叙事评价，也不以字数证明深度。 |
| 不可拆信送达后有正文入口 | Case 01/02 用 `delivery_body_access` 与回执入口授予阅读；结果段落不重复全文。Case 02 需日终后读取。 | 未成功交付不授予阅读；保留初始隐私门槛。 |
| 保存、错投与损坏可恢复 | 自动保存、备份回退、错投重试、物理进度与检查点恢复；测试与演示使用隔离存档。 | 运行证据有明确源码版本；不是跨所有硬件、任意外部损坏的保证。 |
| 30–45 分钟及模拟玩家评审 | 提供多条路线与操作；模拟画像含解谜老手、新手及其他类型偏好，另有确定性路线执行报告。 | 时长是目标，画像不是真人；没有真人满意率，自动演示时长不代表首次游玩。 |

| 参考职责 | 当前落点 | 仍需判断的体验 |
|---|---|---|

| Genuine Article：检查原始物证 | 信封可翻放大；遮挡牌、名单与署名卡实际可观察，物证可放在桌面。 | 视觉证据能否支持推理，而非全靠日志解释。 |
| Forgery Craft：操作影响成品 | 两种工具、失误、有限材料和分步封回，成品保留痕迹。 | 痕迹差异和操作力度是否清楚且公平。 |
| Papers, Please：桌面并置与职业抉择 | 非对称工作面、五封实体纸签、可移动信件与档案卡、急件及交接。 | 并置是否减少记忆负担，而非增加遮挡整理。 |
| Return of the Obra Dinn：交叉事实与延迟确认 | 档案未知项、三项独立物证及身份登记，晚间核对事实。 | 玩家能否解释每条证据的用途；不声称达到原作谜题规模。 |
| HER TREES: PUZZLE DREAM：操作恢复信息 | 六片撕裂标签拖转拼合；遮挡、翻页、薄纸笔迹对齐。 | 地址字符较易读，主要困难在后续地址过期；拼片本身不是中高难逻辑题。 |
| Strange Horticulture：工作面与资料对照 | 桌面保留信件、人物和证物；地图作为可关闭叠层预览旅时与交通。 | 地图开启时不可继续拖桌面卡片，跨资料比较仍有模式切换。 |
| The Westport Independent：删减改变意义 | 照片可从信封移入保留区，正文不改写，材料状态与后果分别保存。 | 后果主要由晚间文本呈现；未扩展成编辑整份出版物。 |
| Orwell: Ignorance is Strength：已知与传递分开 | 身份推断独立于交付；旧清单揭示人为处理，结尾可归档、私留或销毁。 | 不能把事实核对正确误当作对最终处理的道德认可。 |

`Crushed in Time` 仅作为造型与色块的早期参考。最终外景使用绘画素材，不移植参考游戏的代码、模型、音轨或运行时图像。参考名称不能替代对本项目实际玩法的验收。

## 验证入口与报告边界

- [自动化验证记录](testing/AUTOMATED_VALIDATION.json)：各套测试的实际结果、证据类型和运行范围；只对对应运行版本负责，不重复相加宣称独立覆盖量。
- [主场景交互报告](testing/ui_flow_results.json)：真实 Main 中的纸张、证物、对话、旅行与交付接线；是程序输入测试，不是真人可用性结论。
- [完整界面演示记录](testing/playthrough_final_ui.json)：受控路线、源码和资源哈希、运行速度及结束状态；不代表首次游玩时长或商业验收。
- [路线报告](testing/cohort_results.json)、[基线](testing/cohort_baseline.json)、[模拟画像](testing/SIMULATED_PERSONAS_100.json)：确定性核心流程与存档测试；不是真人评价。
- `tests/actor_depth_smoke.gd`、`walker_smoke.gd`：人物前后、地面边界、交谈分离与热点输入回归。`test-results/` 中的临时日志和截图按仓库规则忽略。
- [原件清单](ASSET_INTEGRITY.json)、[展示副本校验](testing/ASSET_DISPLAY_VERIFICATION.json)：验证字节哈希、尺寸、RGB、外围透明度范围；不评价审美。
- [评审依据](testing/PLAYER_REVIEW_BASIS.md)、[评审轮次](testing/REVIEW_ROUNDS.md)、[本轮变更](RELEASE_NOTES.md)：区分历史问题、已做修复与尚未完成的真人和发行终审。

旧截图、旧报告只证明其运行时的状态。新资源或源码变化后，应以对应的新运行记录核对；不能将历史通过数字自动套到最终发行包。
