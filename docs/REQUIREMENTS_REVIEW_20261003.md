## 已解决的规则冲突
| 旧规则 | 当前规则 |
|---|---|
| 完全一样 / 抠取参考 | 借布局与交互框架，形状/配色适配；禁止抠原游戏资产 |
| 全部换新美术 | 保留认可的早间框架/场景，撤掉被否定的空青绿桌面设计 |
| 锁定用户素材必须展示 | 原始素材不改不删；用户后来要求退出运行时的素材不打包 |
| Cases02–05 永久冻结 | 先修既有链；最新三封信内容已授权，隔离实现，不破坏旧五案存档 |
| 生成插画封面 | 最新方向：简约大字游戏名 |
| 三次修不过就停 | 用户要求反复修测试；不把三次当作质量豁免 |
| 阶段等许可 | 已授权修改/main 发布，不重复询问；沉默不等于验收 |
